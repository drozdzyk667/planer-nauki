# Working brand exploration

Candidates: Nuvecto, Codivra, Kernova, Syntrio, Codemori, Lerniq, Codelume, Kernilo, Iterava, Codalith, Nodivra, Loopvra.

Basic exact-name public web searches on 2026-09-18 found obvious software/training conflicts for Codivra, Kernova, Syntrio, Codelume, Iterava and Codalith. Codemori is already used by a developer/blog author; Kernilo has unrelated company/domain uses. Nuvecto returned a domain/DNS reference but no obvious competing programming-learning product in the sampled results. Selected **Nuvecto** as a temporary working name. This is a limited search, not domain availability or trademark clearance. Brand tokens remain centralized and replaceable.

Visual idea: the knowledge core. A luminous glass cube and orbital nodes represent understanding assembled one concept at a time. Learning diagrams use real HTML/SVG labels so both languages and assistive technology receive exact information.
